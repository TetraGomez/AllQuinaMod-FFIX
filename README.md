This mod requires the Memoria Mod to work. Download that first! In the future I will have the mod on the mod catalog in Memoria, but for now here are the manual install instructions:
1.  Install Memoria Mod, then open the game through Steam to open the launcher and update if necessary. Then close the Memoria Launcher.
2.  Open the FINAL FANTASY IX install folder which is accessible from Steam by right clicking the game in the library list then going to "Manage > Browse local files"
3.  Create a new folder in this directoy called "All Quina Mod" or something.
4.  Place all the mod files in this folder.
5.  When you launch the game again, click on the "Mods" tab in the Memoria Launcher and the mod should be listed here. Make sure the gem next to the game is lit so that it is loaded.
6.  Hit play and enjoy!

Currently, there is no ensured compatibility with other mods. If you do encounter an issue when loading with a specific mod, you can email me at tetra.m.gomez@gmail.com with the problem so that I can look into it. At this point in time, just put the mod at the top of the list (highest priority) to make sure the mod files are not written over by other mods. This may cause issues varying in severity including preventing the game from opening.

If you find a balance issue, or have a suggestion for what could be added to the mod, please email me at tetra.m.gomez@gmail.com and I will consider adding it!
